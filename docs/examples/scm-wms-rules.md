# SCM/WMS 规则示例知识库

## 库存可用数量口径

库存可用数量用于回答“还能用多少库存”这类问题。面试演示中可按以下口径说明：

- 可用数量通常等于现存数量减去锁定数量。
- 锁定数量表示已被销售订单、拣货任务或其他业务流程占用的库存。
- 查询具体库存时，应以实时库存 Tool 返回的数据为准，知识库只负责解释计算口径和字段含义。

## 物料状态含义

物料状态用于判断物料是否可以继续参与采购、销售、库存或生产相关流程。

- 启用状态表示物料可以参与正常业务查询和流转。
- 停用状态表示物料不建议继续用于新增业务单据。
- 如果实时 Tool 返回的状态是数字编码，应结合企业主数据字典解释，不应由模型自行猜测。

## 仓库与库位说明

仓库表示库存归属的管理地点，库位表示仓库内部更细粒度的存放位置。

- 查询库存余额时，物料 ID、仓库 ID 通常是必要参数。
- 库位 ID 可用于进一步收窄查询范围。
- 如果用户只查询物料信息，没有表达库存意图，不应自动查询库存余额。
